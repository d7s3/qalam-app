# قلم

منصة رقمية متكاملة للعلوم الشرعية وحلقاتها: تدير البرامج والدفعات، وتتابع
الحضور والحفظ والمراجعة، وتقيس إنجاز كل طالب وتُبلّغ به أسرته.

بُنيت على Laravel و Livewire، بواجهة عربية من اليمين إلى اليسار، وتقويم هجري
يحمل التاريخ الميلادي بجانبه.

## البدء

```bash
composer run setup
```

يثبّت الاعتماديات، ويجهّز `.env` ومفتاح التطبيق، ويهاجر القاعدة، ويبني الأصول.

## التشغيل والاختبار

```bash
composer run dev     # الخادم ومعالج الطوابير و Vite معاً
composer run test    # فحص التنسيق ثم الاختبارات
composer run lint    # تنسيق الشيفرة
```

المجموعة تحتاج ذاكرة أوسع من ١٢٨ ميجا الافتراضية، وإلا انتهت بنفاد ذاكرة لا
بفشل اختبار:

```bash
php -d memory_limit=2G vendor/bin/pest
```

## كيف يعمل

**الهوية** — كل ما يخصّ الجهة في `config/brand.php`: الاسم والشعار والألوان
وبيانات التواصل والوصف. فالتطبيق يخدم أكثر من جهة دون تعديل شيفرة.

**الأدوار** — مدير المركز، ومدير برنامج، ومشرف دفعة، ومعلم دفعة، وطالب، وولي
أمر. والأقدمية تشمل: ما يفتحه المعلّم يفتحه مشرفه، والمدير فوقهما.

**الصلاحيات** — ثلاث طبقات منفصلة، تُضبط كلها من داخل التطبيق:

| الطبقة | ما تقرّره |
|---|---|
| `RoleHierarchy` | أي دور يحمل أي دور |
| `Access` | أي شاشة تُفتح لأي دور — أو لشخص واحد بعينه |
| `Scope` | كم يرى فيها: المركز، أو برنامجاً، أو دفعة، أو نفسه |

ولا تُسأل هذه الأسئلة إلا في هذه المواضع الثلاثة. الشاشات لا تعيد كتابة
«من أرى؟» داخلها، واختبار يمنع رجوع ذلك.

**البرنامج الذاتي** — خمسة مجالات لكل طالب أسبوعاً بأسبوع، ونصيب اليوم يُحسب
من المتبقّي وأيام الدوام لا يُخزَّن.

**التقارير** — فهرس في `app/Services/Reports`. التقرير يُكتب مرة ويقرؤه كل دور
بقدر مدّه، ويُجمَّع بالطالب أو الدفعة أو البرنامج أو المركز، ويُصدَّر جدولاً أو
ورقة. إضافة تقرير سطرٌ في الفهرس لا شاشة.

## المشاركة

- اقرأ [`CLAUDE.md`](CLAUDE.md) — فيه أعراف الشيفرة في هذا المستودع.
- كل تغيير يحتاج اختباراً؛ شغّل `vendor/bin/pint` قبل الدفع.
- أيام الدوام تُقرأ من `AcademicCalendarEvent` وحدها — لا تُحسب في مكان آخر.
- التواريخ تُعرض بـ`<x-hijri-date>` أو `HijriDate::withGregorian()` حيث لا يصلح وسم.

## تنبيه

الأحاديث المعروضة على الصفحة الرئيسية وصفحة الدخول في
`app/Support/KnowledgeHadiths.php`، ومعها تخريجها ودرجتها. **تُراجَع مع مختصّ
شرعيّ قبل أي نشر**، ولا يُضاف فيها إلا ما صحّ أو حَسُن.
